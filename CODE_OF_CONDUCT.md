# Code of Conduct

This project wants to be a friendly place for everyone who uses or improves it.

## Expected behaviour

- Be respectful and patient, especially with newcomers and with people whose first language is not English.
- Discuss ideas, not people. Assume good intentions.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

## Not acceptable

- Harassment, insults, discriminatory jokes or language, personal or political attacks.
- Publishing other people's private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Scope and enforcement

This applies to all project spaces: issues, pull requests, discussions and any other channel where
someone represents the project. The maintainer may edit or remove comments, commits and contributions
that break these rules, and may block repeat offenders.

Report problems privately to the maintainer, **Ankit Chakraborty**, through the contact on his GitHub
profile. Reports are handled confidentially.
